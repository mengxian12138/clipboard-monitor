# 管理脚本说明

这个文件夹包含了各种管理和维护脚本。

## 📁 脚本列表

| 脚本文件 | 功能说明 | 使用场景 |
|---------|---------|---------|
| `安装依赖.bat` | 安装Python依赖包 | 手动安装pywin32等依赖 |
| `后台启动.bat` | 后台静默启动程序 | 不想看到控制台窗口时使用 |
| `停止监控.bat` | 停止所有监控程序 | 程序卡死或需要重启时使用 |
| `设置开机启动.bat` | 设置开机自动启动 | 希望开机自动运行程序 |
| `系统兼容性检查.bat` | 检查系统环境 | 遇到问题时诊断系统环境 |
| `install_python.bat` | 自动安装Python | 系统没有Python时使用 |

## 🚀 推荐使用顺序

1. **首次使用**: 直接运行根目录的 `一键安装运行.bat`
2. **遇到问题**: 运行 `系统兼容性检查.bat` 诊断
3. **日常使用**: 运行根目录的 `启动监控.bat`
4. **后台运行**: 运行 `后台启动.bat`
5. **开机启动**: 运行 `设置开机启动.bat`

## ⚠️ 注意事项

- 大部分脚本需要在项目根目录下运行
- 某些脚本可能需要管理员权限
- 建议先运行兼容性检查，确保系统环境正常
