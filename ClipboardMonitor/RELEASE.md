# 发布说明

## 🎯 项目简介

Windows 剪贴板监控工具 - 一个美观实用的剪贴板监控程序，当你复制文本时会在右下角显示优雅的通知窗口。

## 📦 发布内容

### 核心文件
- `clipboard_monitor.py` - 主程序
- `config.json` - 配置文件
- `requirements.txt` - Python依赖

### 启动脚本
- `一键安装运行.bat` - 推荐使用，自动安装所有依赖
- `启动监控.bat` - 常规启动脚本

### 管理工具 (scripts/)
- `安装依赖.bat` - 手动安装依赖
- `后台启动.bat` - 后台静默运行
- `停止监控.bat` - 停止程序
- `设置开机启动.bat` - 设置开机启动
- `系统兼容性检查.bat` - 系统诊断
- `install_python.bat` - 安装Python

## 🚀 快速开始

1. 下载项目文件
2. 双击运行 `一键安装运行.bat`
3. 程序会自动安装Python和依赖包
4. 开始享受复制监控功能

## 📋 系统要求

- Windows 7/8/10/11 (32位/64位)
- 网络连接 (仅首次安装时需要)
- 512MB 可用内存
- 100MB 磁盘空间

## 🔧 特色功能

- ✅ 美观的深色主题通知
- ✅ 自动置顶显示
- ✅ 3秒渐变消失效果
- ✅ 点击立即关闭
- ✅ 自动记录复制历史
- ✅ 完全便携，无需安装
