# 更新日志

所有重要的项目变更都会记录在这个文件中。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)，

## [1.0.0] - 2025-09-18

### 新增
- ✨ 美观的深色主题通知窗口
- 🔝 自动置顶显示，不会被其他应用遮挡
- ⏰ 3秒后渐变淡出动画效果
- 👆 点击通知可立即关闭
- 📝 自动记录复制历史到日志文件
- 🔧 通过config.json自定义配置
- 🚀 支持开机自启动设置
- 🌍 跨电脑便携使用
- 🎯 一键安装运行功能
- 🔍 系统兼容性检查工具
- 📖 完整的使用文档

### 技术特性
- 支持 Windows 7/8/10/11 (32位/64位)
- 自动检测并安装Python环境
- 智能依赖包管理
- 多种启动方式适配不同用户需求
- 完整的错误处理和用户提示

### 文件结构
- `clipboard_monitor.py` - 主程序文件
- `config.json` - 配置文件
- `一键安装运行.bat` - 自动安装启动脚本
- `便携版启动.bat` - 便携启动脚本
- `系统兼容性检查.bat` - 系统诊断工具
- 完整的管理工具集合
